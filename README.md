An advanced, interactive mobile phone retail store and stock management platform built with React, TypeScript, and Vite. Features power-user tools including a global Command Palette and QR Code integration.

---

## Key Features

- Global Command Palette: Instant navigation and product quick-search with keyboard shortcut (Cmd+K / Ctrl+K) via CommandPalette.
- Real-Time Analytics Hub: Interactive revenue, inventory levels, and best-seller metrics inside AnalyticsView.
- Instant QR Code Sharing: Generate product QR codes on the fly using qrcode.react for mobile checkout and specs viewing.
- Multi-Facet Product Filters: Filter smartphones by brand, processor, RAM, internal storage, and budget tiers.
- Interactive Celebrations: Canvas Confetti animations trigger upon successful order checkout.

---

## Tech Stack

- Language and Framework: TypeScript, React 18
- Tooling: Vite
- Components and Utils: qrcode.react, canvas-confetti, lucide-react
- Styling: Tailwind CSS

## Getting Started

```bash
# Clone the repository
git clone https://github.com/tanzim557/mobile-shop-store.git
cd mobile-shop-store

# Install dependencies
npm install

# Start development server
npm run dev
```
